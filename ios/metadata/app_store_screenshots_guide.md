# App Store Screenshots Guide for IAP Review

## Required Screenshots for In-App Purchase Review

### 1. Premium Subscription Page
- **File Name:** `premium_subscription_page.png`
- **Shows:** Premium features list, pricing, subscription button
- **Required Elements:**
  - Clear subscription price ($4.99/month)
  - List of premium features
  - Subscribe button
  - Terms and privacy policy links

### 2. Purchase Flow Dialog
- **File Name:** `iap_purchase_dialog.png`
- **Shows:** iOS native IAP purchase confirmation
- **Required Elements:**
  - Product name and description
  - Price confirmation
  - iOS purchase dialog
  - Cancel and Buy buttons

### 3. Premium Features Active
- **File Name:** `premium_features_active.png`
- **Shows:** App with premium features unlocked
- **Required Elements:**
  - Premium badge/indicator
  - Unlimited usage indicators
  - Advanced features accessible

### 4. Subscription Management
- **File Name:** `subscription_settings.png`
- **Shows:** Settings page with subscription management
- **Required Elements:**
  - "Manage Subscription" button
  - Current subscription status
  - Link to App Store subscription settings

## Screenshot Specifications
- **Resolution:** 1290 x 2796 pixels (iPhone 14 Pro Max)
- **Format:** PNG
- **Quality:** High resolution, clear UI elements
- **Language:** English
- **Status Bar:** Clean, no low battery or carrier issues

## Upload Instructions
1. Take screenshots using demo account
2. Ensure all premium features are clearly visible
3. Upload to App Store Connect > App Information > App Review Information
4. Add descriptive captions for each screenshot

## Demo Flow for Screenshots
1. Login with demo account
2. Navigate to Premium page → Screenshot 1
3. Tap Subscribe → Screenshot 2
4. After purchase → Screenshot 3
5. Go to Settings → Screenshot 4

## Important Notes
- Screenshots must show actual app functionality
- Demo account should have active subscription
- All UI text must be clearly readable
- No placeholder or lorem ipsum text
- All features must be working/functional
